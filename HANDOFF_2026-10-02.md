## What This Project Does

The user pastes a document into the ClefFace Send page. Each sentence comes back as a fact, a theory, a concept, a step, or no label, with a reading (says yes, says no, only sometimes, not sure) and that model's own score. The page keeps the sentence when the model can name it and read it. A citation such as `[1]` stays on the fact. The labels are the model's reading. They are not clinical truth.

The note used to prove this is `doc2use.md` in this repo (Cladophialophora bantiana / cerebral phaeohyphomycosis). The user expects nearly every sentence in the note to count as a fact. The reference list at the bottom is not the facts. Headings can be skipped.

**Tech stack:** TypeScript, TanStack Start, Vite, React. Local model is MLX `mlx-community/clef-flash-4bit` behind a small Python server. Cloud models are OpenRouter decision models, not chat completions.
**Architecture:** One local web app plus one experiment record. This Cleferred repo is not the running app. Its `README.md` is the upstream ModernJEV model card. Do not fine-tune that model. The user rejected that path.

## Current State Assessment

### What's working
- The Send page keeps a sentence when the model names a fact, theory, concept, or step and the reading is clear. The score is shown. It is not a cutoff.
- A citation is stored as `external_check` and shown as "cites a source." It does not hold the sentence.
- "Not sure," no label, and a split between the top two choices (within 0.08) still wait.
- A says-no reading waits when the sentence has no explicit no/not/never. "fluconazole is poorly active" sent to Mercury on the live page returned `polarity` `denied` and `waiting` true.
- On the whole note, local Clef, Jev, and Liquid keep that fluconazole sentence as says yes. Jev keeps "there is no clearly proven optimal regimen" as says no, because the sentence says no.

Do not describe a larger local model as if it ran.
- The Send page does not save a run. The saved runs are the JSON files in this repo.
- One model cannot see the other models. The page does not compare them. The backwards-reading hold is the words of that one sentence.
- Pasting "fluconazole is poorly active (MIC90 64)." alone to local Clef waits. The full question set returned says yes 0.4286 and says no 0.4220, which is inside the 0.08 split. Inside the whole note, with the neighboring lines, local kept it as says yes at 0.5087. Neighbors change the score.
